# 컴판다 통합 네비게이션

도로·항공·선박 이동을 하나의 모바일 화면에서 연결하는 모듈입니다.

## 1차 구현

- 스마트폰/PWA 반응형 UI
- 현재 위치 권한 처리(브라우저 내부에서만 사용)
- 목적지 이름 + WGS84 위도/경도 입력
- 카카오맵 공식 지도 URL로 목적지 길찾기 실행
- 네이버지도 공식 `nmap://navigation` URL Scheme 호출
- Google Maps 공식 cross-platform URL로 길안내/내비 실행
- TMAP 정식 앱 실행 시도 및 Android Play Store fallback
- 아이나비 에어 정식 App Store/Google Play 연결

## 중요한 통합 원칙

카카오맵, 네이버지도, TMAP, 아이나비, Google Maps의 앱 바이너리나 계정정보를 복제/추출하지 않습니다. 각 사업자가 공개한 URL Scheme, Universal Link, API 또는 SDK만 사용합니다. 외부 앱의 로그인은 해당 앱이 직접 처리합니다.

## 항공 2차 연동

서버에서 아래 공식 데이터 공급원을 연결합니다.

- 국토교통부 TAGO 국내항공운항정보
- 인천국제공항공사 운항정보

화면 흐름: 출발/도착 공항 선택 → 항공편 조회 → 상태/시간 표시 → 공항까지 도로 네비게이션 실행.

## 선박 2차 연동

한국해양교통안전공단 여객선 항해정보 등 공식 데이터 공급원을 서버에서 연결합니다. 이 모듈은 승객용 이동/운항정보 서비스이며 선박 조종·항해 통제용 전자해도/항법장비를 대체하지 않습니다.

화면 흐름: 출항/입항 항만 선택 → 여객선 운항정보 조회 → 운항 상태 표시 → 항만까지 도로 네비게이션 실행.

## API 키

공공데이터 서비스키, Kakao REST API 키, TMAP AppKey, OAuth client secret 등 비밀정보는 브라우저 JavaScript에 넣지 않습니다. 서버 환경변수에 보관하고 서버 API가 외부 공급자와 통신하도록 구성합니다.
